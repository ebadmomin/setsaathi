# SetSaathi Exercise Library Taxonomy & Variations

## Purpose

This is the source structure for the exercise library, plan generator, and future gym-owner plans. It is not medical advice. Stop an exercise that causes sharp pain, dizziness, numbness, or worsening symptoms; seek qualified medical guidance where appropriate.

## Required fields for every exercise

| Field | Purpose |
| --- | --- |
| Name | Clear common exercise name |
| Category | Split, focus muscle, movement pattern, or conditioning |
| Primary / secondary muscles | Enables search and plan generation |
| Equipment | Bodyweight, band, dumbbell, barbell, cable, machine, kettlebell |
| Level | Beginner, intermediate, advanced |
| Instructions | Short, cue-based execution steps |
| Variations | Easier, standard, and harder alternatives |
| Substitute | Similar movement pattern when equipment or comfort differs |
| Risk note | Specific safety cue; never diagnose injuries |
| Media | Licensed GIF/video reference only |

## 1. Training-split categories

### Full body

Use a squat or lunge, hinge, push, pull, core/stability, and optional carry each session.

| Pattern | Starter | Standard | Variation |
| --- | --- | --- | --- |
| Squat | Chair squat | Goblet squat | Barbell back squat |
| Hinge | Glute bridge | Dumbbell Romanian deadlift | Barbell Romanian deadlift |
| Push | Incline push-up | Push-up | Dumbbell bench press |
| Pull | Band row | Dumbbell row | Lat pulldown |
| Core | Dead bug | Plank | Pallof press |

### Push / Pull / Legs (PPL)

| Day | Main muscles | Exercise families |
| --- | --- | --- |
| Push | Chest, front/side shoulders, triceps | Horizontal press, vertical press, fly, lateral raise, triceps extension |
| Pull | Lats, upper back, rear shoulders, biceps | Vertical pull, horizontal row, rear-delt pull, curl |
| Legs | Quads, hamstrings, glutes, calves | Squat, hinge, lunge, curl, extension, calf raise |

Suggested PPL exercise variations:

| Focus | Beginner / home | Dumbbell | Gym / machine or barbell |
| --- | --- | --- | --- |
| Chest | Incline push-up | Floor press | Bench press, chest press |
| Shoulders | Wall slide | Shoulder press | Machine press, cable lateral raise |
| Triceps | Bench-supported extension | Overhead extension | Cable pressdown |
| Back | Band row | One-arm row | Lat pulldown, seated cable row |
| Biceps | Band curl | Hammer curl | Cable curl, preacher curl |
| Quads | Sit-to-stand | Goblet squat | Leg press, back squat |
| Hamstrings | Bridge | Romanian deadlift | Leg curl, barbell RDL |
| Glutes | Hip bridge | Hip thrust | Barbell hip thrust |
| Calves | Two-leg calf raise | Loaded calf raise | Seated / standing calf machine |

### Upper / lower

Upper days combine horizontal and vertical pushes/pulls. Lower days include squat, hinge, single-leg work, calves, and trunk stability. This is a useful four-day template.

## 2. Focus-muscle categories

1. Chest: push-up, dumbbell press, machine chest press, cable fly.
2. Back: row, pulldown/pull-up, face pull, reverse fly.
3. Shoulders: overhead press, lateral raise, rear-delt fly.
4. Arms: curl variants and triceps extension/pressdown variants.
5. Quads: squat, split squat, lunge, leg press, leg extension.
6. Hamstrings/glutes: hip hinge, bridge/hip thrust, leg curl.
7. Calves: standing and seated calf raise.
8. Core: anti-extension (plank/dead bug), anti-rotation (Pallof press), carry, controlled rotation.

## 3. Warm-up, strength, cardio, and recovery

### Warm-up: 6–10 minutes

1. Easy walk, bike, march, or row: 2–4 minutes.
2. Dynamic mobility: shoulder rolls, hip circles, ankle rocks.
3. Pattern rehearsal: bodyweight squats, light rows, unloaded hinges.
4. Use one or more lighter ramp-up sets before heavy compound lifts.

Avoid treating static stretching as the only warm-up; choose movements relevant to the workout.

### Strength

Prioritise compound patterns first: squat, hinge, press, pull, lunge. Typical starting prescriptions are 2–3 sets of 8–12 controlled repetitions; load, sets, and rest must be adjusted for experience, goal, technique, and recovery.

### Cardio / conditioning

| Type | Examples | Use in app |
| --- | --- | --- |
| Low impact | Walk, incline walk, cycle, elliptical | Beginner-friendly steady cardio |
| Moderate | Jog, row, stair climber | Fitness building |
| Intervals | Bike intervals, row intervals, hill walk | Advanced option with recovery guidance |
| Circuits | Bodyweight squat, push-up variation, row, carry | Combined strength/conditioning |

### Recovery / cool-down

Use easy movement followed by comfortable range-of-motion work. Document sleep, soreness, pain, and fatigue separately; they should influence the next plan.

## 4. Safety flags for the app

- Spine-aware: loaded squat, hinge, overhead press, row.
- Knee-aware: deep knee flexion, lunge, impact work.
- Shoulder-aware: overhead press, deep dip, fly.
- Balance-aware: single-leg work, carries, fast direction changes.
- Cardio caution: high-intensity intervals or maximal efforts.

Each warning should say what to do: reduce load/range, select the listed substitute, or skip and consult a professional if pain persists. Do not claim a movement is safe for every injury or condition.

## 5. Data build order

1. Add 10–15 safe, widely accessible exercises per major movement family.
2. Add substitutions before adding advanced variations.
3. Add licensed media after form and safety text are reviewed.
4. Add filters: focus muscle, equipment, level, location, pattern, and safety flag.
5. Only then add highly specific isolation exercises and advanced techniques.
